📖 belier-start 사용 설명서

BELIER 팀이 Claude Code를 쉽게 쓰기 위한 도구입니다. 스킬 이름을 외울 필요 없이, /belier-start 하나만 기억하세요.

1. 이게 뭐예요?

작업할 때 "지금 어떤 도구(스킬)를 써야 하는지" 알아서 골라주는 안내자예요.

비유하면 내비게이션 같은 거예요. 목적지만 말하면 알아서 길을 안내하듯, "지금 뭐 하려고요?"만 답하면 알맞은 스킬을 대신 실행해 줍니다.

2. 설치 (처음 딱 한 번만)

컴퓨터당 한 번만 하면 됩니다. 두 번 할 필요 없어요.

① Claude Code를 엽니다.
② 아래 한 줄을 그대로 복사해서 붙여넣고 보냅니다: 
belier-start 설치: git clone --depth 1 https://github.com/belier-bong/belier-start ~/.claude/skills/belier-start 를 실행한 다음 /belier-start 를 실행해줘
③ 기다립니다. 필요한 도구들이 자동으로 깔립니다 (1~2분).
④ 마지막에 "codex login을 한 번 하세요" 안내가 뜨면 → 코드 리뷰 기능을 쓸 사람만 하면 됩니다. 안 쓸 거면 그냥 넘어가도 돼요.

✅ 여기까지 하면 설치 끝입니다.

3. 매일 쓰는 법

새 작업을 시작하거나, "뭐부터 하지?" 싶을 때 Claude Code에 이렇게 치세요:

/belier-start

그러면 이렇게 진행돼요:

1🤖 "지금 어느 단계예요?" 하고 물어봄
2당신이 골라줌 (아래 4단계 중 하나)
3🤖 알맞은 스킬을 자동 실행 + "이거 썼어요" 알려줌
4🤖 단계가 끝나면 "다음 단계로 갈까요?" 물어봄

4. 4단계가 뭐예요?

일을 4단계로 나눠서, 단계마다 맞는 도구를 씁니다.

단계언제무슨 일을 하나
1. 기획새 기능을 시작할 때뭘 만들지, 만들 가치가 있는지 정리
2. 스펙만들기 전에어떻게 만들지 설계·계획
3. 개발·검증실제로 만들 때코드 작성 + 점검
4. 유지나중에구조 정리·개선
헷갈리면 그냥 /belier-start 치고, 물어보면 답만 하세요. 알아서 안내합니다.

5. 자주 묻는 질문

Q. 설치를 매번 해야 하나요?

아니요. 처음 한 번만 하면 됩니다. 그 뒤로는 /belier-start만 치면 돼요.

Q. 작은 일에도 매번 /belier-start를 써야 하나요?

아니요. 주로 새로 뭔가 시작할 때나 어떤 도구 쓸지 헷갈릴 때 쓰면 됩니다.

Q. codex login이 뭐예요? 꼭 해야 하나요?

코드를 다른 AI가 한 번 더 검토해주는 기능이에요. 코드 작업을 직접 하는 사람만 필요하고, 안 쓰면 건너뛰어도 됩니다.

Q. 설치하다가 "이거 직접 하세요"라고 떠요.

화면에 나온 한 줄을 그대로 복사해서 실행하면 됩니다. 잘 모르겠으면 그 화면을 캡처해서 담당자에게 보여주세요.

Q. 최신 버전으로 업데이트하려면?

Claude Code에 이렇게 치세요: cd ~/.claude/skills/belier-start && git pull 해줘

6. 문제가 생기면

설치가 안 되거나 막히면 → 그 화면을 캡처해서 팀 담당자에게 전달하세요. 캡처 한 장이면 대부분 바로 해결됩니다.
